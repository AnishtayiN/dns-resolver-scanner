# اسکنر DNS — DNS Resolver Scanner

یک ابزار ساده و روزمره برای پیدا کردن سریع‌ترین سرور عمومی DNS بر اساس
تأخیر واقعی (latency). فارسی و راست‌به‌چپ، با رشته‌های انگلیسی.

> **A simple everyday tool that finds the fastest public DNS resolver by
> measuring real latency. Persian-first (RTL) with English strings.**

## چه کاری می‌کند

- برای هر سرور عمومی شناخته‌شده (Cloudflare ،Google ،Quad9 ،OpenDNS
  ،AdGuard ،ControlD — هر کدام با دو IP) یک پرس‌وجوی واقعی DNS برای
  `example.com` می‌فرستد و تأخیر رفت‌وبرگشت را اندازه می‌گیرد.
- پروتکل‌ها: **UDP پورت ۵۳**، **TCP پورت ۵۳** (اگر UDP جواب نداد)،
  **DoT پورت ۸۵۳** و **DoH روی HTTPS** — هر جا که سرور پشتیبانی کند.
- درستی پاسخ بررسی می‌شود: شناسه‌ی تراکنش، کد خطا (RCODE) و اینکه رکورد A
  برگشتی یک IP عمومی معتبر باشد. جواب نادرست به‌عنوان سرعت ثبت نمی‌شود.
- وضعیت هر سرور: **سالم** / **کند** (بالای ۳۰۰ میلی‌ثانیه) / **بدون پاسخ** /
  **پاسخ نادرست**. نتایج بر اساس بهترین تأخیر مرتب می‌شوند.
- ضربه روی هر سرور IP آن را کپی می‌کند؛ خروجی سرورهای سالم به صورت
  **TXT** و **JSON**؛ آخرین اسکن به‌صورت محلی ذخیره می‌شود؛ امکان افزودن
  سرور دلخواه با IP.

## چه کاری نمی‌کند (محدودیت‌های صادقانه)

- نتیجه به شبکه‌ی لحظه‌ی اسکن بستگی دارد؛ سروری که الان سریع است ممکن است
  بعداً کند شود.
- تأخیر DNS فقط بخشی از سرعت اینترنت است؛ روی سرعت دانلود اثر مستقیم ندارد.
- برنامه DNS گوشی را تغییر نمی‌دهد و هیچ تنظیمی در سیستم عوض نمی‌کند؛ فقط
  اندازه می‌گیرد و IP را برای کپی کردن نشان می‌دهد.
- هیچ عددی بدون پرس‌وجوی واقعی نمایش داده نمی‌شود؛ هیچ سرور یا سرعتی
  ساختگی نیست.

## ساخت

```bash
gradle assembleDebug
```

نیازمند JDK 17 و Android SDK (compileSdk 35 ،minSdk 24). نسخه‌ی ریلیز با
تگ `v*` به‌صورت خودکار در GitHub Actions ساخته و منتشر می‌شود.

## حریم خصوصی

برنامه هیچ داده‌ای به جایی نمی‌فرستد؛ پرس‌وجوها فقط به همان سرور DNS که
آزمایش می‌شود فرستاده می‌شوند و تاریخچه فقط روی خود گوشی ذخیره می‌شود.
